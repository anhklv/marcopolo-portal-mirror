# 用語集

システム開発および運用において使用する用語の定義をまとめます。特に会員制度に関する用語は複雑なため、ここで定義された意味で使用します。

## 1. 顧客・会員関連

| 用語 | 英語表記 (Code) | 定義・説明 | 例・備考 |
| :--- | :--- | :--- | :--- |
| **顧客** | Customer | システムに登録されている全ての個人・法人担当者。会員、非会員を問わない。 | |
| **所属社団法人** | Member Type | 顧客が所属している社団法人。<br>・ベンチャー監査役協会<br>・ないかんMeetup<br>※1人の顧客が複数に所属する場合がある。 |
| **会員区分** | Member Category | 社団法人内での契約形態・役割。<br>以下の3つのいずれか。<br>・会員<br>・スポンサー<br>・オブザーバー |
| **会員種別** | Member Type Detail | 契約主体が法人か個人かの区分。 | ・法人<br>・個人 |
| **ベンチャー監査役協会の会員種別** | Audit Member Type | 「ベンチャー監査役協会」の「会員」における、参加形態による種別。 | ・正会員（リアル参加可）<br>・オンライン会員（オンライン限定） |
| **プレミアム会員** | Premium Member | 特定の有料オプション契約有無を示すフラグ。<br>主にベンチャー監査役協会の会員に対して付与される。 | ・あり / なし |
| **非会員** | Non-member | どの社団法人にも属していない顧客。 | |

## 2. イベント関連

| 用語 | 英語表記 (Code) | 定義・説明 | 例・備考 |
| :--- | :--- | :--- | :--- |
| **イベント種別** | Event Type | イベントの主催・開催主体となる社団法人名。 | ・ベンチャー監査役協会<br>・ないかんMeetup<br>・その他 |
| **案内** | Invite / Invitation | イベントへの参加を促すメール送信およびそのプロセス。「招待」という言葉は使用せず「案内」に統一する。 | |
| **回答** | RSVP / Answer | 案内されたイベントへの参加可否をユーザーが送信すること。 | ・参加<br>・不参加<br>・未回答 |
| **アンケート** | Survey | イベント終了後に実施する満足度調査などの事後アンケート。 | |
| **トークン** | Token | 案内メールやアンケートメールに含まれる、個人を特定するための一時的な文字列。ログイン不要で回答するために使用する。 | |

## 3. システム・開発関連

| 用語 | 英語表記 (Code) | 定義・説明 | 例・備考 |
| :--- | :--- | :--- | :--- |
| **管理者** | Administrator | システムの管理画面にアクセスし、顧客管理やイベント運営を行うユーザー。現在は1名を想定。 | |
| **モックアップ** | Mockup | 機能や画面遷移を確認するための試作版アプリケーション。実際のDBには接続せず、固定データやメモリ上のデータで動作する。 | |
