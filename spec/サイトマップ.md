# サイトマップ

マルコポーロ合同会社の顧客管理・イベント管理システムの画面構成と遷移フローです。

## 全体構成

```mermaid
flowchart TD
    Start(["ルート /"]) --> Admin["/admin ダッシュボード"]
    
    Admin --> Customers["/admin/customers 顧客一覧"]
    Admin --> Events["/admin/events イベント一覧"]
    
    Customers --> NewCustomer["/admin/customers/new 顧客登録"]
    Customers --> CustomerDetail["/admin/customers/:id 顧客詳細・編集"]
    
    Events --> NewEvent["/admin/events/new イベント作成"]
    Events --> EventDetail["/admin/events/:id イベント詳細・管理"]
    
    EventDetail --> Attendees["参加状況タブ"]
    EventDetail --> Invite["招待・追送タブ"]
    
    Invite --> RSVP["/events/:id/rsvp ユーザー回答画面"]
    RSVP --> Complete["回答完了画面"]
    
    style Admin fill:#e1f5ff
    style Customers fill:#e1f5ff
    style Events fill:#e1f5ff
    style RSVP fill:#fff4e1
    style Complete fill:#e8f5e9
```

## 画面遷移フロー

### 管理者フロー

```mermaid
sequenceDiagram
    participant Admin as 管理者
    participant Dashboard as ダッシュボード
    participant Customers as 顧客管理
    participant Events as イベント管理
    participant EventDetail as イベント詳細
    
    Admin->>Dashboard: ログイン（モックでは不要）
    Dashboard->>Customers: サイドバーから顧客管理へ
    Dashboard->>Events: サイドバーからイベント管理へ
    
    Customers->>Customers: 新規登録ボタン
    Customers->>Customers: 顧客登録画面
    
    Events->>EventDetail: イベントを選択
    EventDetail->>EventDetail: 招待・追送タブ
    EventDetail->>EventDetail: 顧客を選択して送信
```

### ユーザー回答フロー

```mermaid
sequenceDiagram
    participant User as 招待された顧客
    participant Email as メール
    participant RSVP as 回答フォーム
    participant Complete as 完了画面
    
    Email->>User: 招待メール受信（個別ID付きURL）
    User->>RSVP: URLをクリック
    RSVP->>RSVP: 参加・不参加を選択
    RSVP->>Complete: 送信ボタンをクリック
    Complete->>Complete: 完了メッセージ表示
```

## 主要な機能

### ダッシュボード (`/admin`)
- 総顧客数の表示
- 開催予定イベント数の表示
- 直近のイベント一覧（参加予定数付き）

### 顧客管理 (`/admin/customers`)
- 顧客一覧テーブル表示
- 検索機能（UIのみ、モック）
- Excelインポートボタン（UIのみ、モック）
- 新規登録ボタン

### イベント管理 (`/admin/events`)
- イベント一覧テーブル表示
- ステータス表示（受付中/企画中/終了）
- イベント作成ボタン

### イベント詳細 (`/admin/events/:id`)
- **参加状況タブ**: 参加者リストと回答状況
- **招待・追送タブ**: 顧客を選択して招待メール送信
- 集計サマリ（参加/不参加/未回答の数）
- 未回答者への再送ボタン

### ユーザー回答画面 (`/events/:id/rsvp`)
- イベント情報の表示
- 個人名の表示（トークン認証済み）
- 参加・不参加の選択
- メッセージ入力（任意）
- 送信後の完了画面

## モックアップの確認方法

1. 開発サーバーを起動: `cd mockup && npm run dev`
2. ブラウザで `http://localhost:3000/admin` にアクセス
3. サイドバーから各画面に遷移して確認
