# 要件定義書

マルコポーロ合同会社の顧客管理・イベント管理システムの機能要件を定義します。
複数の管理者が存在し、それぞれ異なる権限を持つことを想定しています。

## 1. 共通機能 (Common)

| ID | 機能名 | 内容 | 備考 |
| :--- | :--- | :--- | :--- |
| CM-01 | 管理者ログイン | メールアドレス/パスワードによる管理者認証機能 | セッション管理機能付き |
| CM-02 | ログアウト | 管理画面からのログアウト機能 | セッションをクリア |
| CM-03 | ログインID変更 | ログインに使用するメールアドレスを変更する機能 | テストメールの送信先にもなる |
| CM-04 | パスワード変更 | ログインに使用するパスワードを変更する機能 | 現在のパスワード、新しいパスワード（12文字以上）、確認用パスワードが必要 |
| CM-05 | 管理者管理 | 管理者アカウントの登録・編集・削除機能 | 特権管理者のみ利用可能 |
| CM-06 | 権限チェック | 管理者の権限に基づいてリソースへのアクセスを制御する機能 | コミュニティ管理者は権限範囲内のリソースのみアクセス可能 |
| CM-07 | 管理者切り替え | 開発・検証用に異なる管理者アカウントに切り替える機能 | 開発メニューから利用可能、モックアップ専用機能 |

## 2. 管理者管理機能 (Administrator Management)

管理者アカウントの管理機能です。特権管理者のみが利用できます。

| ID | 機能名 | 内容 | 備考 |
| :--- | :--- | :--- | :--- |
| AD-01 | 管理者一覧表示 | 登録されている管理者を一覧で表示する。<br>検索機能（氏名、メールアドレス）が可能。 | 特権管理者のみ表示 |
| AD-02 | 管理者登録 | 新規管理者アカウントを登録する。<br>管理者種別（特権管理者、コミュニティ管理者）を選択可能。<br>コミュニティ管理者の場合は対象コミュニティを選択する。 | 特権管理者のみ利用可能 |
| AD-03 | 管理者編集 | 管理者情報を編集する。<br>特権管理者のロールは変更不可。 | 特権管理者のみ利用可能<br>パスワード変更は設定画面（CM-04）から行う |
| AD-04 | 管理者削除 | 管理者アカウントを削除する。 | 特権管理者のみ利用可能、確認画面付き |

### 管理者種別

| 種別 | 説明 | 権限範囲 |
| :--- | :--- | :--- |
| **特権管理者** | システムの全機能にアクセス可能 | 全ての顧客・イベント・管理者管理機能 |
| **コミュニティ管理者** | 特定のコミュニティの管理権限 | 権限範囲内のコミュニティの顧客・イベントのみ |

### 権限制限

コミュニティ管理者の場合、以下の制限があります：

- **顧客管理**: 自分の権限範囲内のコミュニティに所属する顧客のみ閲覧・編集可能
- **イベント管理**: 自分の権限範囲内のコミュニティのイベントのみ作成・編集・閲覧可能
- **イベント案内**: 自分の権限範囲内のコミュニティの顧客のみ案内可能
- **管理者管理**: アクセス不可（特権管理者のみ）
- **非会員**: 特権管理者のみが管理可能

## 3. 顧客管理機能 (Customer Management)

現状のExcel管理からの移行および、日常的な顧客情報のメンテナンスを行う機能です。

| ID | 機能名 | 内容 | 備考 |
| :--- | :--- | :--- | :--- |
| CU-01 | 顧客一覧表示 | 登録されている顧客（会員・非会員）を一覧で表示する。<br>検索・絞り込み（氏名、会社名、所属社団法人など）が可能。 | |
| CU-02 | 顧客詳細表示 | 顧客個人の詳細情報（連絡先、属性、過去の参加履歴など）を表示する。 | |
| CU-03 | 顧客登録・編集 | 管理画面から手動で顧客情報を新規登録・編集する。<br>（名刺交換や紹介での追加用） | |
| CU-04 | 顧客削除（無効化） | 顧客データを論理削除または無効化する。 | 誤操作防止のため物理削除はしない |
| CU-05 | CSVインポート | 既存の顧客管理Excelを取り込み、データベースへ一括登録・更新する。 | 初期データ移行時のみ利用を検討 |
| CU-06 | CSVエクスポート | 顧客データをCSV形式でダウンロードする。 | バックアップや別用途用 |

## 4. イベント管理機能 (Event Management)

イベントの作成から招待、出欠管理までを一貫して行う機能です。

| ID | 機能名 | 内容 | 備考 |
| :--- | :--- | :--- | :--- |
| EV-01 | イベント一覧表示 | 過去・現在・未来のイベントを一覧表示する。<br>イベント種別での絞り込みが可能。 | |
| EV-02 | イベント作成・編集 | イベント名、イベント種別、日時、場所、詳細、回答期限などを設定する。<br>イベント種別は必須項目（デフォルト: ベンチャー監査役の会）。 | |
| EV-03 | 案内対象者選定 | 顧客DBから条件（所属社団法人、会員区分、案内状況など）で検索し、そのイベントの案内リストを作成する。<br>個別に追加選択も可能。案内状況（案内済み/未案内）でのフィルタリングが可能。 | |
| EV-04 | 案内メール送信 | 選定した対象者へ案内メールを一斉（または個別）送信する。<br>個別ID付きURLを自動生成して本文に埋め込む。<br>3ステップフロー（案内者選択→メール文作成→確認・送信）で実行。 | |
| EV-05 | 招待メールテンプレート管理 | 招待メールの本文テンプレートを作成・編集・管理する。 | 必要か確認 |
| EV-06 | 参加状況確認 | イベントごとの「参加」「不参加」「未回答」の集計状況をリアルタイムで確認する。<br>参加者リストに対して氏名・会社名でのフリーワード検索、受付ステータス（参加/不参加/未回答）でのフィルタリングが可能。 | |
| EV-07 | 未回答者への再送 | 「未回答」ステータスの人だけを抽出してリマインドメールを送る。<br>3ステップフロー（送信先確認→メール文作成→確認・送信）で実行。送信先は固定で変更不可。 | |
| EV-08 | アンケートメール送信 | 終了したイベントの参加者に対してアンケートメールを送信する。<br>独自フォームのURLを本文に埋め込む形式。3ステップフロー（送信先選択→メール文作成→確認・送信）で実行。<br>ベンチャー監査役の会のイベントのみ利用可能。 | 終了したイベントのみ表示 |
| EV-10 | アンケート作成・管理 | イベントごとのアンケート設問を作成・編集する機能。<br>固定設問（懇親会、今後の参加、入会勧誘）に加え、自由な設問を追加可能。<br>プレビュー機能付き。ベンチャー監査役の会のイベントのみ利用可能。 | |
| EV-09 | イベント一時停止 | イベントの受付を一時停止・再開する機能。 | 受付中のイベントのみ |

## 5. ユーザー（招待客）向け機能 (User Interface)

イベント招待された顧客が利用するWeb画面です。

| ID | 機能名 | 内容 | 備考 |
| :--- | :--- | :--- | :--- |
| US-01 | 参加回答フォーム | 招待された顧客が参加可否を回答<br>トークンがある場合は直接参加/不参加を選択可能<br>トークンがない場合はメールアドレス入力欄が表示され、イベント参加予定DB（招待DB）に登録されている場合のみ回答可能 | ログイン不要 |
| US-02 | 回答完了画面 | 送信完了後のサンクスページ。 | |
| US-03 | 回答内容変更 | 期限内であれば、同じURLから再度アクセスして回答を変更できる機能。 | |
| US-04 | アンケート回答フォーム | イベント参加者が事後アンケートに回答する機能。<br>イベント種別や所属社団法人に応じて設問が動的に変化する。 | |

## データ項目（想定）

### 顧客データ

#### 必須項目
*   氏名(姓名)
*   メールアドレス
*   所属社団法人（ベンチャー監査役の会 / ないかんMeetup / 非会員 など）
*   ステータス（有効/無効）
*   登録日時

#### 任意項目
*   氏名(セイメイ)
*   サブメールアドレス（最大3つ）
*   会社名・所属
*   電話番号
*   郵便番号
*   都道府県
*   市区町村以下
*   性別
*   上場区分
*   出身業種
*   入会資格
*   会員詳細情報
    *   会員区分（会員、スポンサー、オブザーバー）
    *   会員種別（法人、個人）
    *   ベンチャー監査役の会の会員種別（正会員、オンライン会員）
    *   プレミアム会員フラグ
    *   ベンチャー監査役の会の入会日・脱退日
    *   ないかんMeetupの所属
    *   ないかんMeetupの入会日・脱退日
*   備考（紹介者など）

### 所属社団法人と会員区分の表示パターン一覧

顧客管理画面での所属社団法人・会員区分の表示パターンは以下の通りです。社団法人を上位概念として表示します。

| 所属社団法人 | ベンチャー監査役の会 | ないかんMeetup | プレミアム | 表示内容 |
|---------|-------------------|--------------|----------|---------|
| 非会員 | - | - | - | 非会員 |
| 会員 | - | あり | - | ないかんMeetup(会員) |
| 会員 | 正会員 | - | - | ベンチャー監査役の会(正会員) |
| 会員 | 正会員 | - | あり | ベンチャー監査役の会(正会員) プレミアム |
| 会員 | オンライン会員 | - | - | ベンチャー監査役の会(オンライン会員) |
| 会員 | オンライン会員 | - | あり | ベンチャー監査役の会(オンライン会員) プレミアム |
| 会員 | 正会員 | あり | - | ベンチャー監査役の会(正会員) ないかんMeetup(会員) |
| 会員 | 正会員 | あり | あり | ベンチャー監査役の会(正会員) ないかんMeetup(会員) プレミアム |
| 会員 | オンライン会員 | あり | - | ベンチャー監査役の会(オンライン会員) ないかんMeetup(会員) |
| 会員 | オンライン会員 | あり | あり | ベンチャー監査役の会(オンライン会員) ないかんMeetup(会員) プレミアム |
| スポンサー | - | あり | - | ないかんMeetup(スポンサー) |
| スポンサー | あり | - | - | ベンチャー監査役の会(スポンサー) |
| スポンサー | あり | あり | - | ないかんMeetup(スポンサー) ベンチャー監査役の会(スポンサー) |
| オブザーバー | - | あり | - | ないかんMeetup(オブザーバー) |
| オブザーバー | あり | - | - | ベンチャー監査役の会(オブザーバー) |
| オブザーバー | あり | あり | - | ないかんMeetup(オブザーバー) ベンチャー監査役の会(オブザーバー) |

**合計**: 16パターン

**表示の特徴**:
- 社団法人を上位概念として表示（例：ベンチャー監査役の会(正会員)）
- バッジは横並びで表示
- プレミアムバッジは小さいサイズ（`text-xs`）
- プレミアムバッジはスレートグレー（`bg-slate-600`）

### イベントデータ
*   イベント名
*   イベント種別（ベンチャー監査役の会、ないかんMeetup、その他）
*   開催日時（ISO8601形式、表示は「2028年6月15日(月) 18:00」形式、曜日付き）
*   イベント概要
*   タイムテーブル
*   場所
*   備考
*   回答期限（ISO8601形式、表示は「2028年6月15日(月) 18:00」形式、曜日付き）
*   オンライン参加を可能にするフラグ
*   懇親会を開催するフラグ
*   一時停止フラグ（受付を一時停止しているかどうか）
*   ステータス（動的判定：受付中/開催待ち/終了）
