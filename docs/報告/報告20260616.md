# 開発進捗報告書

報告日: 2026年6月16日  
報告対象期間: 前回報告（2026年6月8日）以降

---

## 概要

不具合の修正、セキュリティ向上、操作性改善を行いました。修正は本番・ステージングへ反映済みです。

---


| 項目                 | 内容                                                                   |
| ------------------ | -------------------------------------------------------------------- |
| ドキュメントのディレクトリの閲覧制限 | 管理者ログインの時のみ閲覧可                                                       |
| 開発用機能の公開制御         | 開発メニューを本番環境で非公開                                                      |
| コミュニティ管理者の編集範囲     | 担当コミュニティの所属のみ編集可。共通データは従来どおり編集可。ないかんmeetupの管理者はベンチャー監査役の会の項目を編集できない。 |
| メールの個別送信           | 案内・リマインド・アンケートで宛先アドレスごとに個別送信。件数表示は顧客人数単位のまま                          |
| 案内・リマインドの送信条件      | 終了したイベントに案内ができていたのを受付中のイベントのみ送信可（画面・サーバー両方）                          |
| イベント関連一覧のページング     | 案内・アンケート・参加状況を顧客一覧と同様の20件ページングに統一                                    |
| リマインド送信先確認         | 「次へ」ボタンを一覧上へ移動し、スクロール領域を拡大                                           |
| 顧客詳細の表示            | イベント関連画面から顧客名クリックで新規タブ表示。タブ表示時は「戻る」非表示                               |
| サイドメニュー            | 「設定」を「パスワード変更」に変更                                                    |
