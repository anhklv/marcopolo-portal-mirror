## 📋 概要

## 🎯 主要な実装機能

### 1. スタイルガイドv2の作成（新規）

#### 1.1 スタイルガイドページの作成
- **ページパス**: `/admin/styleguide`
- **コンセプト**: 「コピペで使える」スタイルガイド
- **構成**:
  - 色（foreground, muted-foreground, primary, destructive, background, muted, accent, card）
  - タイポグラフィ（ページタイトル、セクション見出し、ラベル、本文テキストなど）
  - レイアウト（Stack, SectionHeading, PageHeader, DataItem）
  - フォーム（FormField, CheckboxItem, RadioItem, Input）
  - 部品（Button, ActionButton, Badge, Toast）
  - Import例

#### 1.2 レイアウトコンポーネントの作成
- **Stack**: 縦積みレイアウト。gapで間隔を指定（xs: 4px, sm: 8px, md: 16px, lg: 24px, xl: 32px）
- **SectionHeading**: セクション見出し（h2 + Separator）
- **PageHeader**: ページヘッダー（戻るボタン + タイトル + 説明）
- **DataItem**: 詳細表示用（ラベル + 値の組み合わせ）

#### 1.3 フォームコンポーネントの作成
- **FormField**: Label + Input/Select/Textarea + 補足テキストをまとめるコンポーネント
  - `required` で必須マーク自動付与
  - `description` で補足テキスト表示
  - `error` でエラーメッセージ表示
  - ID自動生成（`React.useId()`）
  - aria属性自動付与
- **CheckboxItem**: Checkbox + Labelをまとめたコンポーネント
- **RadioItem**: RadioGroupItem + Labelをまとめたコンポーネント（RadioGroup内で使用）

#### 1.4 アクションコンポーネントの作成
- **ActionButton**: フォームの決定ボタン用（min-w-32 / h-11）
  - 主要アクション（登録、送信など）だけでなく、副次アクション（戻る、キャンセル、テスト送信など）にも使用可能

### 3. UI/UXの改善

#### 3.1 レイアウトの統一
- **Cardコンポーネントの削除**: フォーム画面からCardコンポーネントを削除し、枠線なしのレイアウトに統一
- **グリッド間隔の統一**: 2列グリッドの間隔を`gap-6`（24px）に統一
- **フォームspacingの統一**: フォーム項目間の間隔を`space-y-6`（24px）に統一

#### 3.2 ボタンの統一
- **ActionButtonの採用**: フォームの決定ボタンにActionButtonを使用
- **ボタンの配置統一**: 削除ボタンの配置とスタイルを統一
  - DialogTrigger内の削除ボタンは`variant="outline"`に`border-destructive text-destructive`を追加
  - モーダル内の実際の削除ボタンは`variant="destructive"`を使用

#### 3.3 スタイルの調整
- **検索バーの統一**: 検索バーの高さを`h-9`（36px）、フォントサイズを`text-sm`に統一
- **テーブルの調整**: テーブルの`font-medium`を削除
- **コミュニティバッジ**: コミュニティバッジのスタイルを調整
- **primary色の調整**: primary色を調整
- **トーストの背景**: トーストメッセージの背景を白に設定
- **プルダウンの背景**: SelectItemに`bg-white hover:bg-gray-100`を適用

#### 3.4 その他の改善
- **cursor-pointerの集約**: cursor-pointerをコンポーネント側に集約（Material UI準拠）
- **アンケート送信画面**: 会員区分バッジをinvite画面と統一
