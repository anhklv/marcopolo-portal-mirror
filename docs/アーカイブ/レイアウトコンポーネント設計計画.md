# レイアウトコンポーネント設計・実装プラン

## 概要
mockup/ にレイアウトコンポーネント（FormField, FormSection）を作成し、スタイルガイドを新規作成する。

## 作業ブランチ
`feature/aoki/mock-update-20260128-redesign`

## 目的
HTMLから大量のspacing系クラス直書きをなくす:
- `gap-2` 約25箇所 → FormFieldで吸収
- `space-y-6` 6箇所 → FormSectionで吸収
- その他の直書きも削減

## 決定済み方針

| 項目 | 決定 |
|------|------|
| 検索バー高さ | h-9（36px） |
| 新規登録ボタン | default（塗り） |
| セクション見出し | h2 + Separator |
| フォームspacing | space-y-6（24px） |
| グリッド間隔 | gap-6（24px） |
| 詳細項目構造 | space-y-1 |
| コンポーネント範囲 | 最小限（FormField, FormSection） |

## 実装ステップ

### Step 0: このプランをdocs/に保存
**ファイル:** `docs/レイアウトコンポーネント設計計画.md`

プロジェクトの設計ドキュメントとして保存。いつでも参照可能にする。

### Step 1: ブランチ作成
```bash
git checkout -b feature/aoki/mock-update-20260128-redesign
```

### Step 2: FormField コンポーネント作成
**ファイル:** `mockup/components/ui/form-field.tsx`

```tsx
interface FormFieldProps {
  label: string
  required?: boolean
  description?: string
  id?: string
  children: React.ReactElement
  className?: string
  error?: string
}
```

**機能:**
- Label + Input/Select/Textarea + 補足テキストをラップ
- `required` で必須マーク（`text-destructive`）自動付与
- `description` で補足テキスト表示
- ID自動生成（`React.useId()`）
- aria属性自動付与

### Step 3: FormSection コンポーネント作成
**ファイル:** `mockup/components/ui/form-section.tsx`

```tsx
interface FormSectionProps {
  title: string
  children?: React.ReactNode
  className?: string
}
```

**機能:**
- h2 + Separator + children
- デフォルト `space-y-6`

### Step 4: 新スタイルガイドページ作成
**ファイル:** `mockup/app/admin/styleguide-v2/page.tsx`

**コンセプト: 「コピペで使える」スタイルガイド**
- 説明文は最小限
- 実際のコードをそのままコピーして使える形で表示
- 「こう書く」の例を先に、「なぜ」は後に

**構成:**
1. **フォーム** - FormField, FormSectionの使用例
2. **レイアウト** - グリッド（2列）、spacing
3. **部品** - Button, Badge, Input等（shadcn/uiそのまま）

**表示形式:**
```
┌─────────────────────────────┐
│ [実際の見た目]              │
├─────────────────────────────┤
│ <FormField label="姓" ...>  │  ← コピペ用コード
│   <Input />                 │
│ </FormField>                │
└─────────────────────────────┘
```

### Step 5: 顧客登録画面に適用（テスト）
**ファイル:** `mockup/app/admin/customers/new/page.tsx`

適用箇所:
- プロフィールセクションの姓名フィールド
- 動作確認後、他のフィールドにも展開

## コンポーネント使用例

### Before
```tsx
<div>
  <h2 className="text-lg font-semibold">プロフィール</h2>
  <Separator className="mt-2" />
</div>
<div className="grid grid-cols-2 gap-4">
  <div className="grid gap-2">
    <Label htmlFor="lastName">姓 <span className="text-destructive">*</span></Label>
    <Input id="lastName" placeholder="例: 山田" value={lastName} onChange={...} />
  </div>
</div>
```

### After
```tsx
<FormSection title="プロフィール">
  <div className="grid grid-cols-2 gap-6">
    <FormField label="姓" required>
      <Input placeholder="例: 山田" value={lastName} onChange={...} />
    </FormField>
  </div>
</FormSection>
```
