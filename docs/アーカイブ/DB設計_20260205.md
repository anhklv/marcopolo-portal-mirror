# DB設計（2026/02/05）

## 概要

PostgreSQL 17 + Prisma でのデータベース設計

## 前提

| 項目 | 決定事項 |
|------|---------|
| RDBMS | PostgreSQL 17 |
| ORM | Prisma |
| ID | 自動採番（autoincrement） |
| 削除方式 | 論理削除（deletedAt） ※イベント・顧客 |
| コミュニティ | マスターテーブル管理 |

## 主要テーブル詳細

### communities（コミュニティマスター）

| カラム | 型 | 説明 |
|--------|-----|------|
| id | INT | PK, 自動採番 |
| code | VARCHAR(50) | コード（venture_auditor等）UNIQUE |
| name | VARCHAR(100) | 表示名 |
| has_survey | BOOLEAN | アンケート機能の有無 |
| sort_order | INT | 表示順 |
| created_at | TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | 更新日時 |

**初期データ:**
- venture_auditor: ベンチャー監査役の会（has_survey: true）
- naikan_meetup: ないかんMeetup
- ai_club: AI部会
- other: その他（イベント専用、顧客・管理者には紐づかない）

### survey_responses（自由設問への回答）

| カラム | 型 | 説明 |
|--------|-----|------|
| id | INT | PK, 自動採番 |
| question_id | INT | FK → survey_questions |
| customer_id | INT | FK → customers |
| survey_token_id | INT | FK → survey_tokens |
| rating | SurveyRating | 4段階評価 |
| reason | TEXT | 理由（自由記述） |
| responded_at | TIMESTAMP | 回答日時 |

**UNIQUE制約:** (question_id, customer_id)

**設計上の注意:**
- survey_id は question_id 経由で取得可能なため保持しない（整合性担保）
- survey_token_id で回答時のトークンを参照（参照整合性担保）

---

### fixed_survey_responses（固定設問への回答）

| カラム | 型 | 説明 |
|--------|-----|------|
| id | INT | PK, 自動採番 |
| survey_id | INT | FK → surveys |
| customer_id | INT | FK → customers |
| survey_token_id | INT | FK → survey_tokens |
| after_party_rating | SurveyRating | 懇親会評価 |
| after_party_reason | TEXT | 懇親会評価理由 |
| future_participation | FutureParticipation | 今後の参加意向 |
| future_participation_reason | TEXT | 参加意向理由 |
| membership | MembershipInterest | 入会意向 |
| membership_reason | TEXT | 入会意向理由 |
| comments | TEXT | ご意見・感想 |
| responded_at | TIMESTAMP | 回答日時 |

**UNIQUE制約:** (survey_id, customer_id)

**null許容条件:**
- after_party_rating/after_party_reason: event.hasAfterParty === true の場合のみ入力
- future_participation/future_participation_reason: 常に入力対象
- membership/membership_reason: ベンチャー監査役の会イベント かつ 非会員の場合のみ入力
- comments: 任意入力

---

### survey_tokens（アンケートトークン管理）

| カラム | 型 | 説明 |
|--------|-----|------|
| id | INT | PK, 自動採番 |
| survey_id | INT | FK → surveys |
| customer_id | INT | FK → customers |
| token | VARCHAR(100) | URL用トークン UNIQUE（全体で一意） |
| sent_at | TIMESTAMP | 送信日時 |
| created_at | TIMESTAMP | 作成日時 |

**UNIQUE制約:** (survey_id, customer_id)

**運用ルール:**
- token は全体でUNIQUE（URLで使用）
- 再送時は既存レコードの sent_at を更新（新規作成しない）
- survey_responses / fixed_survey_responses から FK で参照される

## 実装時の注意点

1. **community.code === 'other' の制約**
   - 顧客のコミュニティに紐づけない
   - 管理者の権限スコープに紐づけない
   - アプリケーション層で制御

2. **subEmailsの制約**
   - 最大3件の制約はアプリケーション層で実装

3. **アンケート固定設問の出し分け**
   - afterParty: event.hasAfterParty === true の場合のみ
   - membership: ベンチャー監査役の会イベント かつ 非会員の場合のみ
