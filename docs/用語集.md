# 用語集

システム開発および運用において使用する用語の定義をまとめます。特に会員制度に関する用語は複雑なため、ここで定義された意味で使用します。

## 1. 顧客・会員関連

| 用語 | 英語表記 (Code) | 定義・説明 | 例・備考 |
| :--- | :--- | :--- | :--- |
| **顧客** | Customer | システムに登録されている全ての個人・法人担当者。会員、非会員を問わない。 | |
| **所属コミュニティ** | Community | 顧客が所属しているコミュニティ。<br>・ベンチャー監査役の会<br>・ないかんMeetup<br>※1人の顧客が複数に所属する場合がある。 | 空配列の場合は非会員 |
| **会員区分** | Member Category | コミュニティ内での契約形態・役割。<br>以下の3つのいずれか。<br>・会員 (member)<br>・スポンサー (sponsor)<br>・オブザーバー (observer) | 会員の場合のみ設定される |
| **契約主体** | Contract Type | 契約主体が法人か個人かの区分。 | ・法人 (corporate)<br>・個人 (individual)<br>会員の場合のみ設定される |
| **ベンチャー監査役の会の会員種別** | Audit Member Type | 「ベンチャー監査役の会」の「会員」における、参加形態による種別。 | ・正会員 (regular) - リアル参加可<br>・オンライン会員 (online) - オンライン限定 |
| **プレミアム会員** | Premium Member | 特定の有料オプション契約有無を示すフラグ。<br>主にベンチャー監査役の会の会員に対して付与される。 | ・あり (true) / なし (false) |
| **ないかんMeetupの所属** | Naikan Affiliation | ないかんMeetupの会員が所属している部門・組織。 | 例：内部監査部門、管理部門長、経理部門、法務部門、CFOなど |
| **非会員** | Non-member | どのコミュニティにも属していない顧客。 | `communities` が空配列の場合 |

## 2. イベント関連

| 用語 | 英語表記 (Code) | 定義・説明 | 例・備考 |
| :--- | :--- | :--- | :--- |
| **イベント種別** | Event Type | イベントの主催・開催主体となるコミュニティ名。 | ・ベンチャー監査役の会<br>・ないかんMeetup<br>・その他 |
| **案内** | Invite / Invitation | イベントへの参加を促すメール送信およびそのプロセス。「招待」という言葉は使用せず「案内」に統一する。 | |
| **回答** | RSVP / Answer | 案内されたイベントへの参加可否をユーザーが送信すること。 | ・参加<br>・不参加<br>・未回答 |
| **アンケート** | Survey | イベント終了後に実施する満足度調査などの事後アンケート。 | ベンチャー監査役の会のイベントのみ利用可能 |
| **トークン** | Token | 案内メールやアンケートメールに含まれる、個人を特定するための一時的な文字列。ログイン不要で回答するために使用する。 | |

## 3. システム・開発関連

| 用語 | 英語表記 (Code) | 定義・説明 | 例・備考 |
| :--- | :--- | :--- | :--- |
| **管理者** | Administrator | システムの管理画面にアクセスし、顧客管理やイベント運営を行うユーザー。 | |
| **特権管理者** | Super Administrator | システムの全機能にアクセス可能な管理者。管理者管理機能を含む全ての機能を利用できる。 | `role: "super"` |
| **コミュニティ管理者** | Community Administrator | 特定のコミュニティ（ベンチャー監査役の会、ないかんMeetup）の管理権限を持つ管理者。権限範囲内の顧客・イベントのみを管理できる。 | `role: "community_admin"`<br>`communityScopes: ["ベンチャー監査役の会"]` |
| **コミュニティスコープ** | Community Scope | コミュニティ管理者が管理できるコミュニティの範囲。複数のコミュニティを管理できる場合もある。 | `communityScopes: ["ベンチャー監査役の会", "ないかんMeetup"]` |
| **権限チェック** | Permission Check | 管理者が特定のリソース（顧客、イベントなど）にアクセスできるかどうかを判定する機能。コミュニティ管理者は自分の権限範囲内のリソースのみアクセス可能。 | |
| **モックアップ** | Mockup | 機能や画面遷移を確認するための試作版アプリケーション。実際のDBには接続せず、固定データやメモリ上のデータで動作する。 | |

## 補足説明

### コミュニティと会員制度の関係

- **コミュニティ**: ベンチャー監査役の会、ないかんMeetupの2つが存在
- **会員区分**: 各コミュニティ内での役割（会員/スポンサー/オブザーバー）
- **契約主体**: 会員の場合のみ、法人か個人かを区別
- **非会員**: どのコミュニティにも所属していない顧客

### データ構造の例

```typescript
// 会員の例（ベンチャー監査役の会の正会員）
{
  communities: ["ベンチャー監査役の会"],
  memberCategory: "member",
  contractType: "corporate",
  auditMemberType: "regular",
  auditMemberPremium: true
}

// ないかんMeetupの会員の例
{
  communities: ["ないかんMeetup"],
  memberCategory: "member",
  contractType: "corporate",
  naikanAffiliation: "内部監査部門"
}

// 非会員の例
{
  communities: [],
  memberCategory: undefined,
  contractType: undefined,
  auditMemberType: undefined,
  auditMemberPremium: false,
  naikanAffiliation: undefined
}
```
