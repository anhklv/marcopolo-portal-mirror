## 2. 共通ロジックの抽出

### 2.1 データ取得パターン
**重複箇所**: `use(params)` + `find()`のパターンが多数
- **対象ファイル**: 全詳細ページ・編集ページ
- **パターン**:
```typescript
const { id } = use(params);
const item = items.find((i) => i.id === id);
```

**提案**: `hooks/use-item-by-id.ts`を作成
```typescript
function useItemById<T extends { id: string }>(
  items: T[],
  id: string | undefined
): T | undefined
```

### 2.4 フォーム送信後の処理
**重複箇所**: `toast.success()` + `router.push()`のパターン
- **対象ファイル**: 全フォーム送信処理

**提案**: `hooks/use-form-submit.ts`を作成
```typescript
const useFormSubmit = () => {
  const handleSuccess = (message: string, redirectPath: string) => {
    toast.success(message);
    router.push(redirectPath);
  };
  return { handleSuccess };
};
```

export function formatDateForInput(dateStr: string): string {
