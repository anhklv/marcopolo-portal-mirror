# 権限設計（2026/02/06）

## 概要

管理者のロールに基づくアクセス制御ルールを定義する。
認可はアプリケーション層（Server Actions / Middleware）で実装し、PostgreSQL RLS は使用しない。

## 前提

| 項目 | 決定事項 |
|------|---------|
| 認可方式 | アプリケーション層（Server Actions + Middleware） |
| PostgreSQL RLS | 不使用（Supabase移行時に検討） |
| 認証 | NextAuth.js（セッションベース） |
| ロール | super / community_admin の2種類 |
| 権限スコープ | admin_communities テーブルで管理（community_admin のみ） |

---

## ロール定義

| ロール | 説明 | 権限範囲 |
|--------|------|----------|
| **super** | 特権管理者 | 全機能・全データにアクセス可能 |
| **community_admin** | コミュニティ管理者 | admin_communities で紐づけられたコミュニティの範囲内のみ |

### community_admin の権限スコープ

- admin_communities テーブルに登録されたコミュニティのみ操作可能
- 複数コミュニティへの紐づけが可能（例: venture_auditor + naikan_meetup + ai_club）
- super ロールは admin_communities を使用しない（全コミュニティにアクセス可能）
- community.code === 'other' はスコープに紐づけない（アプリケーション層で制御）

### 対象コミュニティ

権限スコープの対象となるコミュニティは以下の3つ:

| code | 名称 | アンケート機能 |
|------|------|:--------------:|
| venture_auditor | ベンチャー監査役の会 | あり（has_survey: true） |
| naikan_meetup | ないかんMeetup | なし |
| ai_club | AI部会 | なし |

※ `other`（その他）はイベント専用。顧客・管理者のスコープには紐づかない。super のみ作成・閲覧可能。

## 1. ページ単位のアクセス制御

### 管理画面（/admin 配下）— 認証必須

| ページ | パス | super | community_admin | 備考 |
|--------|------|:-----:|:---------------:|------|
| ダッシュボード | /admin | o | o | 表示データはスコープでフィルタ |
| 顧客一覧 | /admin/customers | o | o | スコープ内の顧客のみ表示 |
| 顧客登録 | /admin/customers/new | o | o | 選択可能なコミュニティに制限あり |
| 顧客詳細 | /admin/customers/:id | o | o | スコープ外の顧客は403 |
| 顧客編集 | /admin/customers/:id/edit | o | o | スコープ外の顧客は403 |
| イベント一覧 | /admin/events | o | o | スコープ内のイベントのみ表示 |
| イベント作成 | /admin/events/new | o | o | 選択可能なコミュニティに制限あり |
| イベント詳細 | /admin/events/:id | o | o | スコープ外のイベントは403 |
| イベント編集 | /admin/events/:id/edit | o | o | スコープ外のイベントは403 |
| 案内メール送信 | /admin/events/:id/invite | o | o | スコープ外は403 + 受付中のみ |
| 未回答者への再送 | /admin/events/:id/remind | o | o | スコープ外は403 + 受付中かつ未回答者ありのみ |
| アンケート送信 | /admin/events/:id/survey | o | o | スコープ外は403 + 終了イベントかつ has_survey のみ |
| アンケート作成 | /admin/events/:id/survey/create | o | o | スコープ外は403 + has_survey のみ |
| 管理者一覧 | /admin/admins | o | x | 403 |
| 管理者登録 | /admin/admins/new | o | x | 403 |
| 管理者編集 | /admin/admins/:id/edit | o | x | 403 |
| パスワード変更 | /admin/settings/password | o | o | 自分のパスワードのみ |
| ログイン | /admin/login | - | - | 未認証でアクセス |

### 開発・検証用ページ

認証必須（/admin 配下のため Middleware で認証チェックを通過した上で）、かつ環境変数 `DEBUG_ADMIN_PANEL=true` の場合のみ表示する。
本番リリース後、クライアント確認完了時に `DEBUG_ADMIN_PANEL` を無効化する。

| ページ | パス | 表示条件 | 備考 |
|--------|------|----------|------|
| 画面一覧 | /admin/sitemap | 認証必須 + DEBUG_ADMIN_PANEL=true | 開発メニューからアクセス |
| スタイルガイド | /admin/styleguide | 認証必須 + DEBUG_ADMIN_PANEL=true | 開発メニューからアクセス |
| 管理者切り替え | （サイドバー開発メニュー内） | 認証必須 + DEBUG_ADMIN_PANEL=true | 開発・検証用 |

※ `DEBUG_ADMIN_PANEL` が未設定または false の場合、これらのページは404を返し、サイドバーの開発メニューも非表示にする。
※ DEBUG条件は認証チェックの**追加条件**であり、認証を代替するものではない。

### 公開画面 — 認証不要

| ページ | パス | 認証 | 備考 |
|--------|------|------|------|
| 参加回答フォーム | /events/:id/rsvp | 不要 | トークンまたはメールアドレスで本人確認 |
| アンケート回答 | /events/:id/survey/:token | 不要 | トークンで本人確認 |

### 非公開ページ

| ページ | パス | 方針 |
|--------|------|------|
| ドキュメント閲覧 | /docs, /docs/[slug] | 本番では非公開（Middleware でブロック or ページ自体を除外） |

## 2. データ単位のフィルタリング

### 顧客データ

| 操作 | super | community_admin |
|------|-------|-----------------|
| 一覧表示 | 全顧客 | スコープ内コミュニティに所属する顧客のみ |
| 詳細表示 | 全顧客 | スコープ内コミュニティに所属する顧客のみ |
| 非会員の表示 | 可 | 不可 |

**フィルタリングロジック:**
```
-- community_admin の場合
SELECT DISTINCT c.*
FROM customers c
JOIN customer_communities cc ON cc.customer_id = c.id
WHERE cc.community_id IN (管理者のスコープ内コミュニティID)
  AND c.deleted_at IS NULL
```

### イベントデータ

| 操作 | super | community_admin |
|------|-------|-----------------|
| 一覧表示 | 全イベント | スコープ内コミュニティのイベントのみ |
| 詳細表示 | 全イベント | スコープ内コミュニティのイベントのみ |

**フィルタリングロジック:**
```
-- community_admin の場合
SELECT e.*
FROM events e
WHERE e.community_id IN (管理者のスコープ内コミュニティID)
  AND e.deleted_at IS NULL
```

### 管理者データ

| 操作 | super | community_admin |
|------|-------|-----------------|
| 一覧表示 | 全管理者 | アクセス不可 |
| 詳細表示 | 全管理者 | アクセス不可 |

## 5. 実装方針

### Middleware（認証・ルーティング制御）

```
/admin 配下のページへのアクセス時:
  1. /admin/login → 通過
  2. セッションの存在を確認
  3. 未認証 → /admin/login にリダイレクト
  4. 認証済み → 通過

/admin/sitemap, /admin/styleguide:
  - DEBUG_ADMIN_PANEL !== 'true' → 404

/docs 配下:
  - 本番では非公開（ブロックまたはページ除外）

/admin/admins 配下:
  - community_admin → 403（Middlewareレベルでブロック可）
```

### Server Actions / Server Components（認可チェック）

**重要: Server Actions だけでなく、Server Component でデータを取得する場合も同じ認可チェックを必ず行う。**
RLS を使用しないため、データにアクセスするすべての経路で一貫してスコープチェックを実施する。

各データアクセスの冒頭で以下を実行する:

```
1. セッションから管理者情報を取得
2. ロールを確認
3. community_admin の場合:
   a. リソースの種類を判定（customer / event / admin）
   b. admin リソース → 403エラー
   c. customer / event リソース → スコープチェック
      - 対象データのコミュニティIDがスコープ内か確認
      - スコープ外 → 403エラー
4. super の場合 → 通過（ただし以下の共通チェックは適用）
5. ロール共通チェック:
   a. アンケート操作 → has_survey チェック
      - イベントのコミュニティが has_survey=true でなければ403
      - super であっても has_survey=false のコミュニティではアンケート操作不可
   b. イベント状態チェック
      - 案内メール送信 → イベントが受付中か確認
      - 未回答者への再送 → イベントが受付中かつ未回答者が存在するか確認
      - アンケート送信 → イベントが終了済みか確認
```

### Repository層（データフィルタリング）

一覧取得系のRepositoryメソッドに、呼び出し元からスコープ情報を渡す:

```
- super → フィルタなし（全データ取得）
- community_admin → WHERE句でスコープ内コミュニティに限定
```

### 権限チェックのヘルパー関数

以下のユーティリティを lib/ 配下に用意する:

| 関数 | 用途 |
|------|------|
| getSession() | セッションから管理者情報を取得 |
| requireAuth() | 未認証時に例外をスロー |
| requireSuper() | super以外で例外をスロー |
| canAccessCustomer(adminId, customerId) | 顧客へのアクセス権を判定 |
| canAccessEvent(adminId, eventId) | イベントへのアクセス権を判定 |
| getScopedCommunityIds(admin) | 管理者のスコープ内コミュニティIDリストを取得 |
| canManageSurvey(admin, event) | アンケート操作権を判定（スコープ + has_survey） |
| checkEventStatus(event, requiredStatus) | イベント状態の前提条件を確認 |

## 6. エッジケース

| ケース | 対応方針 |
|--------|----------|
| community_admin がスコープ外の顧客IDに直接アクセス | 403エラーを返す |
| community_admin がスコープ外のイベントIDに直接アクセス | 403エラーを返す |
| community_admin が非会員を登録しようとする | フォームUIで選択不可 + Server Actionでも弾く |
| 顧客が複数コミュニティに所属し、一方のみスコープ内 | 閲覧・編集可能。**編集時、スコープ外コミュニティの所属情報は変更せず保持する**（Server Action でスコープ内の関連のみ更新し、スコープ外の関連は触らない） |
| community_admin のスコープにコミュニティが1つもない | 全データアクセス不可（空の一覧表示） |
| super が自分自身を削除しようとする | アプリケーション層で禁止 |
| community.code === 'other' のイベント | super のみ作成・閲覧可能 |
| has_survey=false のコミュニティでアンケート操作 | 403エラーを返す（UIでもメニュー非表示） |
| 受付中でないイベントで案内メール送信のURLに直接アクセス | 403エラーを返す |
| 未回答者がいないイベントでリマインドのURLに直接アクセス | 403エラーを返す |
| 終了していないイベントでアンケート送信のURLに直接アクセス | 403エラーを返す |
| DEBUG_ADMIN_PANEL=false の環境で /admin/styleguide 等にアクセス | 404を返す |
