## 前提

| 項目 | 決定事項 |
|------|---------|
| 技術スタック | Next.js 15 + Tailwind CSS v4 + shadcn/ui |
| DB | Supabase (PostgreSQL) |
| ORM | Prisma |
| 認証 | NextAuth.js |
| テスト | Vitest（ユニットテスト） |
| メール配信 | Resend |
| 非同期処理 | Inngest |
| エラー監視 | Sentry |
| デプロイ | Vercel |
| 開発体制 | 自分 + AI |
| ブランドカラー | 未定（後から globals.css の CSS 変数を差し替えるだけで反映可能） |

## 方針

- `_archive/mockup/` のスタイルガイド・UIコンポーネントをベースにコピーし、必要に応じて改善する
- デザインの統一はドキュメントではなく**コンポーネントで強制**する
- Service 層は当面不要。必要になってから追加する
- 設計の詳細は [04-Next.jsベストプラクティス設計案_20260128.md](nextjs設計案/04-Next.jsベストプラクティス設計案_20260128.md) を参照

```
marcopolo-portal/
├── _archive/
│   └── mockup/              # 旧モック（参照・コピー元）

│   ├── admin/               # 管理画面

├── components/
│   ├── ui/                  # shadcn/ui（_archiveからコピー）
│   └── layout/              # レイアウトコンポーネント
├── lib/
│   ├── actions/             # Server Actions
│   ├── repositories/        # データアクセス層
│   ├── validations/         # Zod スキーマ
│   ├── types/               # 型定義
│   └── constants/           # 定数
├── __tests__/               # ユニットテスト（Vitest）
│   ├── lib/                 # lib/ 配下のテスト
│   └── helpers/             # テストヘルパー
├── package.json
└── ...
```
