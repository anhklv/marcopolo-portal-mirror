## 共通化の機会

### [R-001] formatEventDate() の重複（3箇所）
- **優先度**: High
- **該当ファイル**:
  - `lib/utils/event.ts` (6-23行目) — エクスポート済み
  - `lib/mail/templates/invite.ts` (17-31行目) — private関数
  - `lib/mail/templates/remind.ts` (17-31行目) — private関数
- **現状**: `YYYY年6月15日(月) 18:00` 形式への変換ロジックが3箇所に同一コードとして存在する
- **改善案**: `lib/mail/templates/invite.ts` と `remind.ts` の private `formatEventDate()` を削除し、`lib/utils/event.ts` からインポートする
- **影響範囲**: メールテンプレート2ファイル。既存テストへの影響なし

### [R-002] バッチメール送信ロジックの重複
- **優先度**: High
- **該当ファイル**:
  - `lib/actions/invite.actions.ts` (122-143行目)
  - `lib/actions/remind.actions.ts` (89-111行目)
- **現状**: `BATCH_SIZE = 10` での分割送信、`sendMail()` 呼び出し、`sentCount` / `failedCount` / `failedNames` の集計ロジックがほぼ同一
- **改善案**: `lib/mail/send.ts` に `sendMailBatch(mails: {to, subject, body}[])` のような共通関数を追加し、結果を `{sentCount, failedCount, failedNames}` で返す
- **影響範囲**: invite.actions.ts, remind.actions.ts の2ファイル。動作変更なし

### [R-003] Invite/Remind ステップコンポーネントの類似構造
- **優先度**: Medium
- **該当ファイル**:
  - `app/.../invite/_components/step-email.tsx` (59行) / `app/.../remind/_components/step-email.tsx` (60行)
  - `app/.../invite/_components/step-confirm.tsx` (99行) / `app/.../remind/_components/step-confirm.tsx` (102行)
- **現状**: 両方のstep-email.tsxはタイトル文言・戻り先・ステップ定数が異なるのみで構造は同一。step-confirm.tsxもデータソース（selectedCustomers vs pendingCustomers）が異なるのみ
- **改善案**: props でバリエーションを吸収する共通コンポーネント（例: `StepEmailBase`, `StepConfirmBase`）を `events/_components/` に作成し、invite/remind から薄いラッパーとして利用する
- **影響範囲**: 4ファイル。今後同様のメール送信フロー追加時にも再利用可能

### [R-004] ActionResult型の不統一（3種類）
- **優先度**: Medium
- **該当ファイル**:
  - `lib/types/action.ts` (5-8行目) — `{ error?, fieldErrors? }`
  - `lib/actions/auth.ts` (7-9行目) — `{ success: true/false, error }`
  - `lib/actions/event.actions.ts` (18-20行目) — `EventActionResult`（success + eventId）
- **現状**: Server Actionの戻り値型が3パターン存在し、呼び出し側で異なるハンドリングが必要
- **改善案**: `lib/types/action.ts` にDiscriminated Union型（`{ success: true; data? } | { success: false; error; fieldErrors? }`）を定義し、全アクションで統一する
- **影響範囲**: 全アクションファイルおよびフォームのフック。段階的に移行可能
