## 理想の業務フロー (To-Be)

システム導入により、顧客データの**一元管理**と、イベント参加管理の**自動化・セルフサービス化**を実現します。

*   **完全案内制**: 管理者がシステムから案内した人のみが回答可能。
*   **ワンクリック認証**: 個別ID付きURLにより、顧客は面倒な入力作業が不要。
*   **柔軟な配信**: 一斉配信だけでなく、後からの追加案内や個別配信も随時可能。
*   **自動リマインド**: 未回答者への自動リマインドメール送信機能。
*   **アンケート配信**: 終了したイベントの参加者へのアンケートメール送信機能。

```mermaid
flowchart TD
    %% 定義
    subgraph Daily ["マルコポーロ (随時)"]
        NewContact[名刺交換・紹介など]
        AdminRegister["管理画面で顧客登録<br/>(会員・非会員)"]
    end

    subgraph Admin ["マルコポーロ (イベント時)"]
        Start([イベント企画])
        CreateEvent["管理画面でイベント作成<br/>(日時・内容)"]
        
        subgraph InvitationLoop ["案内・追送プロセス (随時)"]
            SelectTarget["システム上で配信対象を<br/>検索・選択・追加<br/>(会員区分、案内状況でフィルタ)"]
            SystemSend["案内メール配信<br/>(一斉 or 個別)"]
            RemindSend["未回答者へのリマインドメール送信"]
        end
        
        CheckStatus[管理画面で参加状況をリアルタイム確認<br/>(検索・フィルタ機能付き)]
        Finish([イベント当日へ])
        
        subgraph AfterEvent ["イベント終了後"]
            SurveySend["参加者へのアンケートメール送信<br/>(GoogleフォームURL付き)"]
        end
    end

    subgraph User ["対象者"]
        ReceiveMail("メールを受信<br/>(個別ID付きURL)")
        AccessForm["Web参加フォームへアクセス<br/>(名前入力不要)"]
        InputForm[参加・不参加ボタンを押す]
    end

    subgraph System ["新システム"]
        DB[("顧客・イベントDB")]
        AutoUpdate[回答内容を自動集計・ステータス更新]
    end

    %% フロー
    NewContact --> AdminRegister
    AdminRegister -- "登録" --> DB

    Start --> CreateEvent
    CreateEvent -- "登録" --> DB
    CreateEvent --> SelectTarget
    SelectTarget -- "対象抽出" --> DB
    SelectTarget --> SystemSend
    
    SystemSend -.-> SelectTarget
    SystemSend -- "個別URL生成＆配信" --> ReceiveMail
    
    CheckStatus -.-> RemindSend
    RemindSend -- "未回答者のみ抽出" --> DB
    RemindSend -- "リマインドメール配信" --> ReceiveMail
    
    ReceiveMail --> AccessForm
    AccessForm --> InputForm
    
    InputForm -- "送信" --> AutoUpdate
    AutoUpdate -- "自動更新" --> DB
    
    DB -.-> CheckStatus
    CheckStatus --> Finish
    
    Finish --> SurveySend
    SurveySend -- "参加者のみ抽出" --> DB
    SurveySend -- "アンケートメール配信" --> User

    %% スタイル調整
    classDef system fill:#9cf,stroke:#333,stroke-width:2px;
    class AdminRegister,CreateEvent,SelectTarget,SystemSend,RemindSend,SurveySend,AutoUpdate,DB system;
```
